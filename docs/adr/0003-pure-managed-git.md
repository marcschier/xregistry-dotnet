# Own the managed Git acquisition and verification contract

Git access must work through the NuGet libraries without Git executables,
checkout prerequisites, or native Git assets. None of the inspected managed
libraries qualifies the complete acquisition, integrity, security and Native-AOT
contract unchanged, so use one narrow owned acquisition/object-reader module
with selective licensed reuse only after executable qualification. Do not
substitute archive downloads or silently accept unresolved SHA-1 collision risk
to avoid that engineering work.
