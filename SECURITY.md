# Security

This project is under development and is not yet qualified for production use.
Its required controls and evidence are documented in
[docs/security.md](docs/security.md).

Do not disclose credentials or sensitive registry data in public reports. Use
GitHub private vulnerability reporting for this repository when that facility is
available. Until a private reporting channel is configured, do not post
exploitable details or private data in a public issue.

Security fixes must preserve explicit failure behavior and include regression
evidence. Removing a guard, swallowing a failure, or suppressing all analyzer
warnings is not an acceptable compatibility workaround.
